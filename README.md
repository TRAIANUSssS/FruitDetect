# FruitDetect

FruitDetect — это веб-приложение для детекции и подсчёта фруктов (яблоки, бананы, апельсины) на изображениях и видео. Приложение использует модель YOLOv8 для сегментации объектов, OpenCV для обработки файлов и FastAPI для бэкенда. Фронтенд построен на React с использованием Tailwind CSS.

## Возможности
- Загрузка изображений (`.jpg`, `.png`) или видео (`.mp4`).
- Выбор категорий фруктов для детекции (яблоки, бананы, апельсины).
- Обработка файлов с выделением фруктов цветными масками и подписями.
- Отображение количества обнаруженных фруктов в таблице.
- Просмотр обработанных изображений и видео в браузере.

## Системные требования
- **Операционная система**: Windows 10/11, macOS или Linux.
- **Python**: 3.8 или выше.
- **Node.js**: 16.x или выше.
- **FFmpeg**: Установленный и добавленный в `PATH` для обработки видео.
- **CUDA** (опционально): Для ускорения обработки на GPU с YOLOv8.
- **Дисковое пространство**: ~2 ГБ для зависимостей и моделей.
- **ОЗУ**: Минимум 8 ГБ (рекомендуется 16 ГБ для видео).

## Установка

### 1. Клонируйте репозиторий
```bash
git clone <repository-url>
cd FruitDetect
```

### 2. Установите FFmpeg
FFmpeg необходим для конвертации видео в формат, совместимый с браузерами.

#### Windows
1. Скачайте FFmpeg с [gyan.dev](https://www.gyan.dev/ffmpeg/builds/) (выберите `ffmpeg-git-full.7z`).
2. Распакуйте архив в `C:\ffmpeg`.
3. Добавьте `C:\ffmpeg\bin` в системную переменную `PATH`:
   - Нажмите `Win + R`, введите `sysdm.cpl`, перейдите в **Дополнительно → Переменные среды**.
   - В **Системные переменные** найдите `Path`, добавьте `C:\ffmpeg\bin`.
4. Проверьте установку:
   ```bash
   ffmpeg -version
   ```

#### macOS
```bash
brew install ffmpeg
```

#### Linux
```bash
sudo apt-get install ffmpeg
```

### 3. Установите зависимости Python
1. Создайте и активируйте виртуальное окружение (рекомендуется):
   ```bash
   python -m venv venv
   source venv/bin/activate  # Windows: venv\Scripts\activate
   ```
2. Установите зависимости:
   ```bash
   pip install -r req.txt
   ```

## Запуск приложения

### 1. Запустите бэкенд
В первом терминале:
```bash
cd E:\Projects\FruitDetect
uvicorn backend:app --host 0.0.0.0 --port 8000
```
Бэкенд будет доступен на `http://localhost:8000`.

### 2. Запустите фронтенд
В другом терминале:
```bash
cd E:\Projects\FruitDetect\frontend
npm start
```
Фронтенд автоматически откроется в браузере на `http://localhost:3000`. Если порт 3000 занят, React предложит другой порт (например, 3001).

## Использование
1. Откройте `http://localhost:3000` в браузере.
2. Выберите файл:
   - Изображение (`.jpg`, `.png`) или видео (`.mp4`).
   - Рекомендуемый размер видео: до 50 МБ, кодек H.264.
3. Выберите категории фруктов для детекции (яблоки, бананы, апельсины).
4. Нажмите **Process** и дождитесь обработки.
5. Результат:
   - **Fruit Counts**: Количество обнаруженных фруктов.
   - Обработанное изображение или видео с цветными масками и подписями.

## Устранение неполадок
- **Порт 3000 занят**:
  ```bash
  netstat -aon | findstr :3000
  taskkill /PID <PID> /F
  ```

- **FFmpeg не найден**:
  - Убедитесь, что `ffmpeg` добавлен в `PATH` (см. раздел установки).
  - Проверьте: `ffmpeg -version`.
